# 搜索与个人中心的第一版取舍

- 商品广场只展示 `ON_SALE`，按发布时间和 ID 倒序分页；搜索词用参数绑定并转义 `%`、`_`，避免它们被当作通配符。第一版对标题和描述使用包含查询，适合当前的小数据量。数据量增加后再按真实查询和 `EXPLAIN` 结果评估全文索引或搜索服务。
- 商品列表与用户表关联读取发布者昵称，页面展示真实发布者。没有商品时只显示标注为“示意卡片”的占位内容，不伪装成真实商品。
- `GET /api/products/me` 按 JWT 中的用户 ID 查询最近 100 件商品，包含已预订和已下架状态；该接口必须在公开商品详情的权限匹配之前要求认证。订单购买列表同样按 JWT 用户 ID 查询，不能由客户端指定其他用户。
- 商品图片尚未入库，前端根据商品信息显示图形占位封面；图片上传和大规模列表翻页另行实现。
